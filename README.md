# SARV Infotech Web Development Internship

This repository contains the tasks completed for the SARV Infotech web development internship.

## Level 1: Simple Calculator

The calculator is a beginner-friendly project built with semantic HTML, responsive CSS Grid styling, and vanilla JavaScript.

### Features

- Addition, subtraction, multiplication, and division
- Decimal calculations and negative results
- Clear (`AC`), delete (`DEL`), and equals controls
- Division-by-zero protection and input length protection
- Responsive layout for desktop and mobile screens

### Technologies

- HTML5
- CSS3
- JavaScript (ES6)

## Level 2: Gurveer Arora Tribute Page

A responsive HTML and CSS tribute to Gurveer Arora and his pure-CSS calculator experiment. The page uses semantic HTML, an editorial layout, and CSS-only animation—there is no JavaScript.

### Highlights

- Verified story and technical details from Gurveer Arora's original Scott Logic article
- CSS-only technique diagram, calculator illustration, timeline, and animations
- Accessible reduced-motion mode and responsive layouts
- Credited local portrait and direct links to the original article, code, and calculator

### Primary sources

- [Original NoJS calculator article](https://blog.scottlogic.com/2022/01/20/noJS-making-a-calculator-in-pure-css-html.html)
- [QuarkNerd/noJS source repository](https://github.com/QuarkNerd/noJS)
- [Live NoJS calculator](https://quarknerd.github.io/noJS/calc.html)
