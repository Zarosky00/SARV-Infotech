02 / The method

How CSS became
the engine.

The trick was not one secret feature. It was a chain of familiar browser tools, pushed far beyond their usual jobs.

01 <input type="radio">

State without scripts

Hidden radio inputs remember which number or operation the user selects.

02 :checked ~ element

Labels become controls

Labels act like buttons while sibling selectors reveal and route each selected value.

03 --digit: 7;

Variables carry values

Custom properties pass selected digits through carefully nested HTML.

04 calc(a + b)

CSS does the maths

The calc function combines chosen numbers and operators into a real result.

05 @counter-style

Counters print the answer

Typed properties and custom counters handle rounding, decimals, signs, and display.
